# Somalite

**Intelligent School Operating System** — school command center + academic intelligence engine + AI assistant platform, built for low-bandwidth mobile-first environments.

> This PR contains the **foundation only**: auth with default credentials, role hierarchy RBAC, modular folder structure, ORION AI routing skeleton, activity logging, soft-suspend/deactivate status (no deletes), and glassmorphism mobile-first UI. Feature modules (exams, templates, analytics, packages UI, bus tracking, HR, discipline) will follow in subsequent PRs.

## Stack

- **Backend:** Laravel 11 · PHP 8.3
- **Frontend:** Blade (SSR) + vanilla JS + single static CSS file (no build step)
- **Database:** MySQL (production) / SQLite (local + tests)
- **Maps:** Google Maps API (bus tracking — Elite tier, future)
- **AI:** ORION router → Claude / OpenAI / Gemini / DeepSeek (auto-selected)

## Quick start

```bash
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Default System Admin (seeded):

- **Username:** `system platform`
- **Password:** `ADMIN`  *(first login forces a password change)*

Override via env: `SEED_ADMIN_FIRST_NAME`, `SEED_ADMIN_MIDDLE_NAME`, `SEED_ADMIN_LAST_NAME`, `SEED_ADMIN_EMAIL`.

## Credential convention

All users are created with the same rule:

| Field    | Value                                       |
|----------|---------------------------------------------|
| Username | `firstname middlename` (lowercase)          |
| Password | `LASTNAME` (uppercase)                      |
| Flag     | `must_change_password = true` on first login|

## Role hierarchy

Lower `level` = higher authority. See `App\Models\Role::catalog()`.

```
 0  system_admin              (global)
10  director                  (school)
20  deputy_director
30  school_admin
40  academic_head
50  deputy_academic_head
55  examination_master
60  hr / it / department_head
65  discipline_head
70  deputy_discipline_head
80  teacher
90  student / parent
```

Exam override precedence (highest first):
`director → school_admin → academic_head → deputy_academic_head → examination_master`.
An exam generated by the Director is **locked to the Director**.

## ORION AI routing

Users *always* interact with the brand **"ORION AI"**. Only System Admin sees which real provider was used.

| Task              | Primary   | Fallback chain                         |
|-------------------|-----------|----------------------------------------|
| `report`          | Claude    | → OpenAI → Gemini → DeepSeek           |
| `explanation`     | OpenAI    | → Claude → Gemini → DeepSeek           |
| `data_analysis`   | Gemini    | → OpenAI → Claude → DeepSeek           |
| `generic`         | Claude    | → OpenAI → Gemini → DeepSeek           |

Configure providers via `.env`:

```
ANTHROPIC_API_KEY=
OPENAI_API_KEY=
GEMINI_API_KEY=
DEEPSEEK_API_KEY=
```

Every ORION request is logged in `ai_requests` with task type, provider, latency, and token usage.

## Data rules

- **No hard deletes.** Users and schools carry a `status` column: `active`, `suspended`, `deactivated`.
- **Activity log** (`activity_logs`) records `auth.login`, `auth.logout`, `auth.password_changed`, `orion.ask`, and any `log(action, subject, props)` call through `App\Services\ActivityLogger`.


16 tests cover: auth flow (login / forced password change / suspended user / bad credentials), role hierarchy (`outranks`, username/password conventions), ORION routing (primary provider per task type, graceful failure when none configured), and basic routing (root redirect, login renders, health check).

## Performance

- Single static CSS file (~5 KB), no JS framework, no build step.
- Mobile-first viewport, `16px` inputs to avoid iOS zoom.
- Blade SSR; only the ORION widget uses a tiny `fetch` call.
- CSRF + session cookies only — no SPA bundle to download.
